Raster2Seq: Interactive Visualization

This explorer surfaces paired raster inputs and vectorized floorplan outputs from Structured3D, CubiCasa5K, and Raster2Graph, together with per-sample structural and semantic metrics.

Quick Notes

  • Each sample compares the rasterized input against the predicted vectorized floorplan, so you can inspect reconstruction quality at the example level.
  • FRI-Net performs structural reconstruction only. When a model does not predict semantics, the rendered output floorplan is shown in yellow .

Browse Results

Choose a dataset and model to inspect matching samples. When you switch models, the viewer tries to keep you on the same input image so comparisons stay grounded.
